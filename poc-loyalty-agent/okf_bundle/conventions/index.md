# Conventions & Governance

This directory defines standardized date arithmetic, SQL authoring style, cost and security limits, PII protection, and visualization rendering standards.

## Standards Directory
- [Date Window Rules](/conventions/date-windows.md): Rolling windows relative to `CURRENT_DATE()` and Calendar YTD definitions.
- [SQL Authoring Style](/conventions/sql-style.md): Read-only CTE format, parameterization, and partition filters.
- [Cost & Row Limits](/conventions/cost-and-row-limits.md): `MAX_BYTES_BILLED` thresholds, mandatory dry runs, and default row caps.
- [PII Masking Standards](/conventions/pii-masking.md): Redaction rules for email addresses and member names.
- [Visualization Standards](/conventions/visualization-standards.md): Chart conventions (UC2a pie chart, UC5 green/red variance bar chart).
